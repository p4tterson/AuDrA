AuDrA is a convolutional neural network that is finetuned to judge how creative your drawings are. 
The code in this repo, from [Patterson et al. (2024)](https://link.springer.com/content/pdf/10.3758/s13428-023-02258-3.pdf), was used to run a hyperparameter search ('computational experiment') and train the best fitting model. 
AuDrA was trained using drawings from Barbot's (2018) Muti-Trial Creative Ideation task available at https://osf.io/h4adm/
