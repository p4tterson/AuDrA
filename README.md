Code associated with [https://link.springer.com/content/pdf/10.3758/s13428-023-02258-3.pdf] (Patterson et al. (2024)) used to run a hyperparameter search ('computational experiment') and train the best fitting model. 
AuDrA was trained using drawings from Barbot's (2018) Muti-Trial Creative Ideation task available at https://osf.io/h4adm/
